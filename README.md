# 🎬 YouTube Downloader

A simple YouTube video and audio downloader built with **Python, Flask, and yt-dlp**.

The application allows users to paste a YouTube URL, view the video information, select a format and quality, and download the media.

## ✨ Features

- 🎬 Download videos as MP4
- 🌐 Download videos as WebM
- 🎵 Download audio as MP3
- 📺 Select video quality:
  - Best Available
  - 1080p
  - 720p
  - 480p
  - 360p
- 🎧 Select MP3 quality:
  - 128 kbps
  - 192 kbps
  - 256 kbps
  - 320 kbps
- 🖼️ Displays video thumbnail
- 📝 Displays video title
- 📊 Displays download progress
- ⚡ Shows download speed
- 💻 Simple web interface
- 📱 Responsive design

## 🛠️ Technologies Used

- Python
- Flask
- yt-dlp
- HTML
- CSS
- JavaScript
- FFmpeg
